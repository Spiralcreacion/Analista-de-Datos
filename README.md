# Análisis de datos de logística

Se analizan los datos de una empresa de logística para conocer los tiempos de demora en los despachos.

**Dataset:** DataCo Smart Supply Chain, publicado en Mendeley Data.

**Herramientas:**
- PostgreSQL
- Power BI
- Python

# Problema de negocio

¿Cuánto se retrasan los despachos y qué dinero está asociado a esos pedidos retrasados?
